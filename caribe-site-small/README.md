# Caribe Services website

Static HTML website for Caribe Services, with project photos and Google Voice number (260) 222-6166.

## Deploy to GitHub Pages

1. Create a public GitHub repository, e.g. `caribe-services-website`.
2. Upload all contents of this folder (including `.github/workflows/pages.yml`), to branch `main`.
3. In repository **Settings → Pages → Build and deployment**, set **Source** to **GitHub Actions**.
4. The workflow publishes after each push to `main`. The URL will be `https://YOUR-USERNAME.github.io/caribe-services-website/`.
5. To use `caribe-services.com`, set a custom domain in Pages settings and configure domain DNS with your registrar following GitHub's current documentation. Do not change DNS until the Pages URL works.

The site's contact form opens a mailto draft; it does not collect messages server-side. Text buttons link to 260-222-6166.
