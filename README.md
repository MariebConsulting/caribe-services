# Caribe Services Website

Production website source: Caribe Services, Fort Wayne, Indiana.

The completed website package is prepared as `caribe-services-github-pages-ready.zip`, with original installation photography, French-drain excavation imagery, and the Google Voice contact number (260) 222-6166.

## Deploy
Unzip the complete website into the repository root. Push to `main`. In **Settings → Pages**, choose **GitHub Actions** as the publishing source. The workflow at `.github/workflows/pages.yml` publishes the site on changes to `main`.

Website: https://MariebConsulting.github.io/caribe-services/
